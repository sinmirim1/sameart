# 대칭 아트 스튜디오: 수학으로 만드는 현대미술

초등학교 5~6학년 미술 × 수학 융합 웹앱입니다.
선대칭·점대칭 도형을 만들고 입체파·초현실주의·팝아트 작품으로 완성한 뒤, 설명을 써서 PNG·PDF로 저장합니다.
(수학 5-2 「합동과 대칭」 연계)

- 서버 없이 브라우저만으로 동작합니다.
- 학생 작품은 각 기기의 브라우저에만 저장되며, 어디로도 전송되지 않습니다.
- 첫 화면의 그림은 피카소·마그리트·워홀의 화풍을 본떠 도형으로 새로 그린 것입니다.

이 저장소에는 빌드된 `index.html` 한 파일만 있습니다. GitHub Pages로 배포합니다.
